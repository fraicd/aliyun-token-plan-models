## 多模态模型和内置工具：图像、视频也在额度里

多模态能力覆盖视觉理解、图像生成、语音合成、实时语音对话、语音识别和视频生成，全部走同一份 Credits 额度。

有几个直接影响用量的事实需要提前知道：

- **视频生成的 Credits 消耗随时长和分辨率上涨**，一次调用可能吃掉一大块额度。官方的建议很实在：第一次先选短时长、低分辨率，在订阅页的用量明细里看清单次实际消耗，再决定要不要放量。
- **异步任务是完成后再结算**，不是提交时扣费。短时间内提交多个视频任务，等它们全部完成时 Credits 会一起结算，额度可能在你看不见的地方瞬间见底。
- **图像类模型不能通过通用文本接口直接调**。第三方介绍提到，需要借助所接 AI 工具的扩展能力，通过 Skill 插件、专属命令或 Agent 扩展机制启用。

模型之外，套餐还内置了联网搜索、代码解释器等模型工具，同样按 Credits 计费。Standard 和 Pro 两档额外包含 Harness 权益：AgentStudio 工具的月度免费额度和后付费折扣，这部分独立计量，不占 Credits 也不占用量包，Lite 和 Essential 没有这项。

## Credits 怎么扣：这几点决定额度能撑多久

每次调用消耗多少 Credits，由四个因素动态决定：模型类型、token 用量、是否开启思考模式、有没有工具调用。同样是问一个问题，带深度思考的推理请求比普通对话贵，带联网搜索或代码解释器的请求还要叠加工具部分的消耗。

夜间折扣是官方给的控制成本的抓手：22:00 到次日 08:00（UTC+8）之间，qwen3.8-max 和 qwen3.8-flash 的 Credits 消耗减免 60%，deepseek-v4 系列三款减免 50%。换算下来，同样的额度在这个时段相当于平时 2 到 2.5 倍的用量（视模型而定）。批量处理长文档、跑大批推理任务这类不赶时间的工作，放到深夜做最划算。

扣减顺序本身不复杂：先扣当期订阅月的套餐额度，用完自动扣 Extra Bundle，两者都没有了服务暂停。重置也不用操作，每个订阅月开始时额度自动恢复满额。

## 常见问题

### Token Plan 和 Coding Plan 是一回事吗？

不是。两者是相互独立的订阅产品，不支持迁移或互相升级。Coding Plan Lite 已于 2026 年 3 月 20 日停售新购，4 月 13 日起停止续费和升级；Coding Plan Pro 是限量商品，售完即止。官方现在的推荐就是 Token Plan，模型和内置工具的覆盖也更广。

### 月度额度用完了会立刻断吗？

会暂停服务，直到下一个订阅月。急用的话买 Extra Bundle 补充：100 元一个、20,000 Credits、最多同时持有 5 个，套餐额度用完后自动抵扣，不用手动操作。

### 夜间折扣具体几点到几点？

22:00 到次日 08:00（UTC+8）。qwen3.8-max、qwen3.8-flash 减免 60%，deepseek-v4-pro-0813、deepseek-v4-flash-0731、deepseek-v4.1-flash 减免 50%。注意这是限时活动，具体以官方页面的最新说明为准。

### 图像和视频模型怎么调用？

不能走通用文本接口，要通过工具的 Skill 插件或 Agent 扩展机制启用。视频生成第一次先选短时长、低分辨率试消耗，确认单次扣多少 Credits 再放量；多个视频任务别在短时间内集中提交，异步结算集中到账时额度消耗会很突然。

### 不想用了能退吗？

按月订阅、当月额度不结转；第三方文章梳理的规则是套餐一经订阅不支持退款退订。所以别一次性囤太多用量包，先按一两个月的真实用量选档，不够再补。
